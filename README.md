# FinDesk Banking System

## Project Summary
FinDesk Banking System is a cross-platform desktop banking application built using ElectronJS. It is designed to simplify core banking operations, account management, and transaction tracking through a clean and user-friendly desktop interface.

## Key Features
- **Account Management:** Create, view, and manage customer bank accounts securely.
- **Transactions:** Perform deposits, withdrawals, and fund transfers seamlessly.
- **Dashboard & History:** View real-time account balances and detailed transaction histories.

## Technologies Used
- **Framework:** ElectronJS
- **Frontend:** HTML5, CSS3, JavaScript (`index.html`, `renderer.js`)
- **Backend / Main Process:** Node.js (`main.js`, `preload.js`)

## Installation & Build
This application is bundled for multiple operating systems:
- **Windows:** `.exe`
- **Linux:** `.deb` / `.AppImage`
- **macOS:** `.dmg`
